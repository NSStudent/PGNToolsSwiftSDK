# Opening names

`a.tsv` to `e.tsv` are copied unchanged from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)
at commit `3ba6b20d31b2e6125cb0e6a2e792f400717d9d39`.

The data set is in the public domain. Insofar as its curation qualifies for
copyright, it is released under the
[CC0 1.0 Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).

Each row holds an ECO code, an English opening name and the PGN moves of a
well known line that reaches the named position.
